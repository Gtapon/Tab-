顧客ID一括取得

8桁の顧客IDをまとめて貼り付け → 顧客ページを順番に子ページで開いて文字を取得 → 表にまとめます。

インストール

下のボタンをブックマークバーにドラッグ＆ドロップしてください。

🔎 顧客ID一括取得

ドラッグできない場合は、適当なページをブックマークしてから URL 欄を下のコードに書き換えてください。

使い方

  1. 顧客ページと同じサイトのタブ（ログイン済み）でブックマークをクリックします。操作パネルが子ページで開きます。
  2. 「顧客ページのURL」に、顧客IDの手前までのURLを入れます（例：https://example.com/customer/detail?id=）。途中にIDが入る場合は {id} と書きます（例：https://example.com/c/{id}/info）。
  3. 「取得する項目」を決めます。
    • 📍ページで選ぶ：見本の顧客ページが開くので、取りたい文字をクリックするだけで列が追加されます（続けて何個でも）。
    • 手入力する場合は「項目名の右/下の値」に 契約状態 のように画面上の見出しを書くと、その横（下）の値を取ります。
    • 何も設定しなければ「ページ全体の文字」を取ります。
  4. 顧客IDを改行区切りで貼り付けて「表にセット」。8桁でまとまった数字だけが残り、それ以外（記号・名前・桁違いの数字）は自動で消えます。
  5. 「▶ 開始」で、上から順に子ページを開いて文字を取得し、IDの右に入れていきます。終わると子ページは閉じます。
  6. 「📋 Excel用コピー」でそのまま Excel に貼り付けられます。

止まった行（✖）はその行の ▶ で取り直せます。「▶ 開始」をもう一度押すと、未取得・エラーの行だけを続きから処理します。

安全性について

  • 外部への通信は一切しません。開くのは、入力したURLの顧客ページ（同じサイト）だけです。
  • 取得した顧客情報は操作パネルの中だけに保持し、ブラウザには保存しません（パネルを閉じると消えます）。
  • ブラウザに保存するのは「URL」と「取得する項目の設定」だけです。
